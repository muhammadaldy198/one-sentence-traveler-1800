One sentence (189 characters) that explains the modern internet to a traveler from the year 1800 — one road joining post office and library across the whole earth, a letter posted in London reaching a farmer in Ohio before his coffee cools, any book you name opening on your table. Written using only words a person from 1800 would know. The program writes the sentence to `/output/entry.txt`, deterministically, with no network access.

## Run it

```sh
node main.ts
```

Requires Node 22.18 or later (the grader runs Node 22.23.4).
